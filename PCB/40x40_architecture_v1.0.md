# 40×40 织物压力矩阵 PCB 架构方案 v1.0

**基于 ARCH 1.0 (8×8) 验证结果的扩展设计**
**日期：** 2026-08-20
**目标：** 将已验证的零电位 TIA 读出架构从 8×8 扩展到 40×40，并以 PCB 替代飞线
**PCB 工具：** 嘉立创 EDA (LCEDA)
**制板：** 嘉立创 PCB

---

## 1. 扩展目标与约束

### 1.1 从 8×8 到 40×40 的关键变化

| 维度 | 8×8 (ARCH 1.0) | 40×40 (本方案) | 倍率 |
|---|---|---|---|
| ROW 数 | 8 | 40 | 5× |
| COL 数 | 8 | 40 | 5× |
| 像素总数 | 64 | 1600 | 25× |
| TIA 通道 | 8 | 40 | 5× |
| 运放芯片数 | 4× MCP6002 | 10× MCP6004 | — |
| ROW MUX 芯片 | 1× 74HC4051 | 3× 74HC4067 | — |
| ADC 通道需求 | 8 | 5 (经后级复用) | — |
| 每行上拉电阻 | 8× 100kΩ | 40× 100kΩ | 5× |
| 传感器连线 | 16 根 | 80 根 | 5× |
| 反馈网络 | 8× (Rf+Cf) | 40× (Rf+Cf) | 5× |

### 1.2 不变的核心原则

以下原则在 8×8 验证中已被确认有效，40×40 严格继承：

1. **零电位架构**：所有 COL 由 TIA 同时钳位在 VREF 附近，未选中 ROW 由 100kΩ 上拉到 VREF，实现 sneak path 抑制。
2. **逐行扫描**：每个时刻仅选中 1 个 ROW 拉低到 GND，其余 39 个 ROW 保持 VREF。
3. **RAW 电压输出**：固件输出原始 ADC 值，不做压力换算。
4. **TIA 参数冻结**：Rf = 10kΩ，Cf = 100pF，VREF ≈ 1.03V（与 8×8 一致，后续可按需调整）。

### 1.3 设计形态选择：NUCLEO 扩展板

**推荐方案：模拟前端（AFE）扩展板 + 现有 NUCLEO-H743ZI2。**

理由：
- 你已经有调通的 NUCLEO 板和固件，MCU 部分的电源、晶振、调试接口、VCP 串口均已验证。
- 自己画 LQFP144 最小系统对初学者难度过大（焊接、电源设计、高速信号）。
- AFE 板通过 Morpho 排针直接插到 NUCLEO 上，只需要关注模拟电路部分。
- 迭代成本低——AFE 板出问题只改 AFE 板，MCU 侧不受影响。

因此本方案设计的是一块 **AFE 扩展板（shield）**，通过排针连接 NUCLEO-H743ZI2 的 Morpho 接口。

```
┌──────────────────────────────────────────────────────┐

│         40 根 ROW (经线)  ×  40 根 COL (纬线)          │

         ▼                             ▼
┌─────────────────┐          ┌──────────────────────────┐
│  ROW 选择网络    │          │    40 路 TIA 阵列         │
│  3× 74HC4067    │          │    10× MCP6004           │
│  (16:1 MUX)     │          │    (每颗 4 路 TIA)        │
│                 │          │    Rf=10kΩ, Cf=100pF     │

         │                    │  每组 8 路 → 1 路      │
         │                    └──────────┬────────────┘
         │                              │ 5 路模拟信号
         ▼                              ▼
┌──────────────────────────────────────────────────────┐
│              NUCLEO-H743ZI2                           │
│                                                       │
│  GPIO: ROW 控制 (S0-S3 + E0-E2)  = 7 pin            │
│  GPIO: COL MUX 控制 (S0-S2)       = 3 pin            │
│  ADC:  5 通道模拟输入              = 5 pin            │
│  UART: VCP (USART3)               = 已有              │
│                                                       │
│  总共需要 NUCLEO 引出: 15 pin + 电源                    │
└──────────────────────────────────────────────────────┘
```

### 2.1 为什么 COL 不能复用 / 必须全并行 TIA

零电位架构的核心要求是：**扫描任何一行时，所有 40 根 COL 必须同时被 TIA 钳位在 VREF**。

如果 COL 侧也用模拟开关做选择（像 ROW 那样），未被选中的 COL 将浮空，失去零电位保护，sneak path 电流重新出现。这正是 8×8 H3 实验验证的关键——零电位模式 vs 浮空模式的串扰差距达 5 倍以上。

因此：
- **40 路 TIA 必须全部并行存在**，不能在 TIA 前做 COL 复用。
- 复用只能发生在 **TIA 输出端**（post-TIA mux），此时信号已经是低阻抗的运放输出，可以安全地通过模拟开关。

## 3. ROW 选择网络设计

### 3.1 方案选型：3× 74HC4067

| 方案 | 芯片 | 数量 | 控制GPIO | 优缺点 |
|---|---|---|---|---|
| A | 74HC4051 (8:1) | 5 颗 | 3(S) + 5(E) = 8 | 芯片多，E线多 |
| **B (推荐)** | **74HC4067 (16:1)** | **3 颗** | **4(S) + 3(E) = 7** | **芯片少，通道余量** |
| C | 74HC154 + MOSFET | 3+40 | 6 | 器件太多，不推荐 |

**推荐方案 B：3× 74HC4067**

- MUX_ROW_0：Y0~Y15 → ROW0~ROW15
- MUX_ROW_1：Y0~Y15 → ROW16~ROW31
- MUX_ROW_2：Y0~Y7 → ROW32~ROW39（Y8~Y15 空置）

控制逻辑：
- S0/S1/S2/S3 共享（4 GPIO）
- E0/E1/E2 独立（3 GPIO），同一时刻最多 1 个 E 为低（使能）

每根 ROW 仍通过 100kΩ 上拉到 VREF。选中 ROW 由 4067 的 Z（接 GND）拉低。

### 3.2 74HC4067 关键参数

| 参数 | 典型值 | 对本项目的影响 |
|---|---|---|
| Ron | 80Ω @ 3.3V | 选中 ROW 不是精确 0V，而是 ~80Ω×I，影响很小 |
| 漏电流 | ±0.1µA | 低于 100kΩ 上拉电流 (10µA)，可接受 |
| 切换时间 | ~20ns | 远快于 T_SETTLE，无影响 |
| VCC | 2~10V | 3.3V 供电 |

### 3.3 ROW 网络接线表

```
74HC4067 #0 (MUX_ROW_0):
  VCC = 3V3
  GND = GND
  VEE = GND (单电源)
  Z/COM = GND
  S0 = GPIO_ROW_S0
  S1 = GPIO_ROW_S1
  S2 = GPIO_ROW_S2
  S3 = GPIO_ROW_S3
  E  = GPIO_ROW_E0
  Y0~Y15 → ROW0~ROW15

74HC4067 #1 (MUX_ROW_1):
  同上，E = GPIO_ROW_E1
  Y0~Y15 → ROW16~ROW31

74HC4067 #2 (MUX_ROW_2):
  同上，E = GPIO_ROW_E2
  Y0~Y7 → ROW32~ROW39
  Y8~Y15 → 悬空（不接）
```

### 3.4 100kΩ 上拉电阻网络

40 颗 100kΩ 电阻，每颗一端接一根 ROW，另一端接 VREF 总线。

PCB 布局建议：排成 2 行 × 20 列 或 4 行 × 10 列的电阻阵列。使用 0402 或 0603 封装节省空间。也可以使用排阻（如 4×100kΩ 排阻），减少焊接数量。

## 4. COL TIA 阵列设计

### 4.1 方案选型：10× MCP6004

| 方案 | 芯片 | 数量 | 封装 | 总引脚 |
|---|---|---|---|---|
| A | MCP6002 (双运放) | 20 颗 | SOIC-8 | 160 |
| **B (推荐)** | **MCP6004 (四运放)** | **10 颗** | **SOIC-14/TSSOP-14** | **140** |
| C | OPA4340 或其他 | 10 颗 | TSSOP-14 | 140 |

**推荐 MCP6004**：与 MCP6002 完全兼容的四运放版本，同系列 datasheet，参数一致，仅封装不同。每颗 4 路运放，10 颗正好 40 路。

### 4.2 MCP6004 引脚分配

每颗 MCP6004 (14-pin SOIC/TSSOP) 内部 4 路运放:

```
Pin 1  = VOUTA    → TIA 输出 A
Pin 2  = VINA-    → COL 输入 A (反相输入)
Pin 3  = VINA+    → VREF
Pin 4  = VSS      → GND
Pin 5  = VINB+    → VREF
Pin 6  = VINB-    → COL 输入 B
Pin 7  = VOUTB    → TIA 输出 B
Pin 8  = VOUTC    → TIA 输出 C
Pin 9  = VINC-    → COL 输入 C
Pin 10 = VINC+    → VREF
Pin 11 = VDD      → 3V3
Pin 12 = VIND+    → VREF
Pin 13 = VIND-    → COL 输入 D
Pin 14 = VOUTD    → TIA 输出 D
```

### 4.3 TIA 通道分配

| 芯片 | 通道 A | 通道 B | 通道 C | 通道 D |
|---|---|---|---|---|
| U1 (MCP6004) | COL0 | COL1 | COL2 | COL3 |
| U2 | COL4 | COL5 | COL6 | COL7 |
| U3 | COL8 | COL9 | COL10 | COL11 |
| U4 | COL12 | COL13 | COL14 | COL15 |
| U5 | COL16 | COL17 | COL18 | COL19 |
| U6 | COL20 | COL21 | COL22 | COL23 |
| U7 | COL24 | COL25 | COL26 | COL27 |
| U8 | COL28 | COL29 | COL30 | COL31 |
| U9 | COL32 | COL33 | COL34 | COL35 |
| U10 | COL36 | COL37 | COL38 | COL39 |

### 4.4 每路 TIA 反馈网络

每路 TIA 的反相输入与输出之间并联：
- Rf = 10kΩ (0402/0603)
- Cf = 100pF (0402/0603)

总计：40× 10kΩ + 40× 100pF = 80 颗被动元件。

### 4.5 运放供电去耦

每颗 MCP6004 的 VDD(Pin11) 与 VSS(Pin4) 之间放置 100nF 去耦电容（0402/0603），**紧贴芯片**。

总计：10× 100nF 去耦。

额外在 3V3 模拟总线上放置 1× 10µF 钽电容或 MLCC。

## 5. Post-TIA COL 复用网络

### 5.1 为什么需要后级复用

STM32H743ZIT6 (LQFP144) 的 ADC 外部通道总数无法直接覆盖 40 路。通过在 TIA 输出端（低阻抗信号）加入模拟开关进行分组复用，可以用少量 ADC 通道读取全部 40 路。

关键：复用发生在 TIA **输出端**，不影响 TIA 对 COL 的钳位。所有 40 路 TIA 始终工作，零电位架构完整保持。

### 5.2 分组方案：5× 74HC4051

将 40 路 TIA 输出分为 5 组，每组 8 路：

| MUX | 输入 (TIA 输出) | 输出 (→ ADC) |
|---|---|---|
| MUX_COL_0 | COL0~COL7 的 TIA 输出 | → ADC_CH0 |
| MUX_COL_1 | COL8~COL15 的 TIA 输出 | → ADC_CH1 |
| MUX_COL_2 | COL16~COL23 的 TIA 输出 | → ADC_CH2 |
| MUX_COL_3 | COL24~COL31 的 TIA 输出 | → ADC_CH3 |
| MUX_COL_4 | COL32~COL39 的 TIA 输出 | → ADC_CH4 |

5 片 74HC4051 的 S0/S1/S2 共享 3 根 GPIO，所有 5 片同步切换。E 引脚全部接 GND（始终使能）。

### 5.3 扫描顺序

对每个 ROW：

```
1. 选中 ROW_n (通过 74HC4067)
2. 等待 T_SETTLE (500µs)
3. for mux_pos = 0 to 7:
     设置 COL MUX S0/S1/S2 = mux_pos
     等待 T_MUX_SETTLE (~2µs)
     同时采集 5 路 ADC (ADC_CH0~CH4)
     → 得到 COL[mux_pos], COL[8+mux_pos], COL[16+mux_pos],
            COL[24+mux_pos], COL[32+mux_pos]
4. 现在拥有 ROW_n 的全部 40 个 COL 值
5. 进入下一 ROW
```

### 5.4 COL MUX 接线

```
74HC4051 MUX_COL_x (x = 0~4):
  VCC = 3V3
  GND = GND
  VEE = GND
  E/INH = GND (始终使能)
  S0 = GPIO_COL_S0
  S1 = GPIO_COL_S1
  S2 = GPIO_COL_S2
  Y0~Y7 = 对应 8 路 TIA 输出
  Z/COM = → STM32 ADC 对应通道
```

## 6. ADC 策略

### 6.1 通道分配

只需要 5 个 ADC 通道。可以全部使用 ADC3（与 8×8 保持一致），或分布在 ADC1/ADC3 上。

推荐使用 ADC3 的 5 个通道（与现有固件兼容性最好）：

| ADC 通道 | STM32 引脚 | 来源 |
|---|---|---|
| ADC3_INP9 | PF4 | MUX_COL_0 → COL0~7 |
| ADC3_INP4 | PF5 | MUX_COL_1 → COL8~15 |
| ADC3_INP8 | PF6 | MUX_COL_2 → COL16~23 |
| ADC3_INP3 | PF7 | MUX_COL_3 → COL24~31 |
| ADC3_INP6 | PF10 | MUX_COL_4 → COL32~39 |

这样仅用 5 个 ADC 通道（从原来的 8 个减少到 5 个），PC0/PC1/PC2 空出可作他用。

### 6.2 ADC 配置

- 使用 ADC3，5-rank 规则序列
- DMA 传输
- 采样时间保持保守值（64.5 cycles 或更高）
- 每个 MUX 位置做 N_AVG 次平均（初始 16 次）
- 分辨率：16-bit（与现有一致）

### 6.3 MUX 建立时间

74HC4051 切换后，ADC 输入需要稳定。TIA 输出阻抗很低（~几十Ω），4051 导通电阻 ~80Ω，ADC 输入电容 ~5pF：

τ = (Rout_TIA + Ron_4051) × C_ADC ≈ (50 + 80) × 5pF ≈ 0.65ns

实际考虑 PCB 走线电容和寄生效应，T_MUX_SETTLE 设 2~5µs 即可。

## 7. 帧率估算

### 7.1 单帧扫描时间

```
每行时间 = T_SETTLE + 8 × (T_MUX_SETTLE + N_ADC × T_ADC_CONV)
         = 500µs + 8 × (2µs + 16 × 5µs)
         = 500µs + 8 × 82µs
         = 500µs + 656µs
         = 1156µs ≈ 1.16ms

每帧时间 = 40 × 1.16ms = 46.4ms

帧率 ≈ 21.6 Hz
```

### 7.2 优化空间

| 优化手段 | 预估提升 |
|---|---|
| T_SETTLE 降到 200µs | 帧率 → ~30Hz |
| N_AVG 降到 8 | 帧率 → ~30Hz |
| 两者同时优化 | 帧率 → ~45Hz |
| DMA + 连续转换 | 进一步提升 |

8×8 实测 ~15.7Hz，40×40 在同等参数下 ~21Hz 是合理的（ROW 数 ×5，但 ADC 通道数从 8 减到 5，加上后级 mux 8 步开销）。

对于织物压力矩阵应用，20~30Hz 通常足够。

## 8. VREF 与电源设计

### 8.1 VREF 负载分析

40×40 模式下 VREF 负载：
- 40× 100kΩ 上拉（仅 1 个选中 ROW 消耗 ~10µA，其余无电流）：~10µA
- 40× TIA 非反相输入（MCP6004 输入偏置电流 ~1pA）：~40pA ≈ 0
- 分压器自身静态电流：~1mA
- **总计：~1.01mA**

与 8×8 几乎相同。静态上看，原来的 2.2kΩ/1kΩ 分压器仍然可用。

### 8.2 推荐：增加 VREF 缓冲

虽然静态负载变化不大，但 40×40 的动态环境更复杂：
- ROW 切换时的瞬态电流更大（更多的寄生电容）
- 40 路 TIA 参考点的一致性要求更高
- PCB 布线更长，VREF 分配到 10 颗运放 + 40 颗上拉电阻的走线阻抗

**推荐方案：增加 1 颗 MCP6002 作为 VREF 缓冲。**

```
3V3 → 2.2kΩ → [VREF_RAW] → 1kΩ → GND
                    |
          10µF + 100nF 滤波
                    |
              MCP6002 A路
              Pin3(V+) = VREF_RAW
              Pin2(V-) = Pin1(Vout)  ← 100% 负反馈 (Unity-gain buffer)
              Pin1(Vout) = VREF_BUF ← 这就是全板 VREF
                    |
         → 40× 100kΩ 上拉
         → 10× MCP6004 V+
```

MCP6002 B 路备用（可用于板上测试点缓冲等）。

### 8.3 电源

| 电源轨 | 来源 | 用途 | 估算电流 |
|---|---|---|---|
| 3V3 | NUCLEO 板 3.3V 输出 | 所有模拟芯片 | ~15mA |
| GND | NUCLEO 板 GND | 公共地 | — |

3V3 来自 NUCLEO 的 CN11/CN12 Morpho 排针。NUCLEO 板的 3.3V LDO 通常可提供数百 mA，15mA 绰绰有余。

在 AFE 板入口处放置：
- 10µF MLCC → GND
- 100nF MLCC → GND

## 10. 传感器连接器设计

### 10.1 80 线连接方案

40 ROW + 40 COL = 80 根传感器引线需要接入 PCB。

推荐方案（按易用性排序）：

| 方案 | 连接器 | 优点 | 缺点 |
|---|---|---|---|
| **A (推荐)** | **2× 2.54mm 2×20P 排针** | 易焊、易插拔、通用 | 体积大 |
| B | 2× 0.5mm 40P FPC 座 | 紧凑 | 需要定制 FPC 排线 |
| C | 4× 2.54mm 1×20P 排针 | 最简单 | 占板边长 |

**推荐方案 A：2 个双排 2×20P 2.54mm 排针座**

- J_ROW：40P 排针，接 40 根 ROW 线
- J_COL：40P 排针，接 40 根 COL 线

这样传感器的引线可以用杜邦线一一插入，方便调试和更换。

### 10.2 排针定义

J_ROW (2×20P):

```
Pin 1  = ROW0     Pin 2  = ROW1
Pin 3  = ROW2     Pin 4  = ROW3
...
Pin 39 = ROW38    Pin 40 = ROW39
```

J_COL (2×20P):

```
Pin 1  = COL0     Pin 2  = COL1
Pin 3  = COL2     Pin 4  = COL3
...
Pin 39 = COL38    Pin 40 = COL39
```

## 11. PCB 设计建议（嘉立创 EDA）

### 11.1 板子尺寸

建议 PCB 尺寸：**100mm × 80mm**（双面板）

与 NUCLEO-H743ZI2 的 Morpho 排针对齐，做成可以直接堆叠的扩展板。NUCLEO 板宽 70mm，长 133mm。AFE 板可以稍小或等宽。

### 11.2 分区布局

```
┌────────────────────────────────────────────┐
│  [J_ROW]                        [J_COL]    │  ← 传感器连接器在板顶
│                                            │
│  ┌──────────┐    ┌────────────────────┐    │
│  │ROW MUX   │    │  TIA 阵列           │   │
│  │3×HC4067  │    │  10× MCP6004       │   │
│  │+ 40×100k │    │  + 40×(Rf+Cf)      │   │
│  └──────────┘    └────────────────────┘    │
│                                            │
│  ┌──────────┐    ┌────────────────────┐    │
│  │VREF 生成  │    │  COL MUX           │   │
│  │+ 缓冲    │    │  5× HC4051         │   │
│  └──────────┘    └────────────────────┘    │
│                                            │
│  [=== Morpho CN11 ===]  [=== Morpho CN12 ===] │  ← 底部排针插入 NUCLEO
└────────────────────────────────────────────┘
```

### 11.3 关键布局原则

1. **模拟/数字分区**：TIA 阵列和 VREF 区域为模拟区，MUX 控制信号为数字区。两者用地平面隔离但最终单点连接。

2. **地平面**：使用完整地平面（底层），不要切割。这是最重要的抗干扰措施。

3. **VREF 走线**：VREF 从缓冲器输出后，用较宽走线（≥0.5mm）分配到 10 颗 MCP6004 和 40 颗上拉电阻。避免菊花链（daisy-chain），采用星形或总线分支拓扑。

4. **去耦电容位置**：每颗 IC 的去耦电容必须紧贴 VDD/VSS 引脚，过孔直连地平面。

5. **TIA 输入走线**：COL 信号线到 TIA 反相输入的走线尽量短，避免平行走线串扰。

6. **反馈元件**：Rf 和 Cf 紧贴 MCP6004 的输出和反相输入引脚。

### 11.4 嘉立创 EDA 操作提示

1. **创建工程**：新建 PCB 工程，先画原理图再转 PCB。
2. **器件库**：嘉立创自带库中搜索 MCP6004、74HC4067、74HC4051 等。LCSC 编号直接关联库存。
3. **封装选择**：
   - MCP6004：SOIC-14 或 TSSOP-14（推荐 SOIC-14，手焊更容易）
   - 74HC4067：SOIC-24 或 TSSOP-24
   - 74HC4051：SOIC-16 或 TSSOP-16
   - 电阻电容：0603（手焊友好）或 0402（省空间）
4. **设计规则**：嘉立创默认 DRC 规则即可，线宽 ≥ 0.15mm，间距 ≥ 0.15mm。
5. **层数**：双面板（2层）即可。如果布线困难，可升级到 4 层（嘉立创也支持，费用略高）。

## 13. 固件改动要点

### 13.1 主要变化

| 模块 | 8×8 | 40×40 | 改动量 |
|---|---|---|---|
| ROW 扫描 | 3-bit S + 1 E | 4-bit S + 3 E | 中等 |
| ADC 序列 | 8-rank | 5-rank | 小 |
| COL MUX | 无 | 3-bit S, 8 步内循环 | 新增 |
| 串口协议 | R0~R7, 8 列 | R0~R39, 40 列 | 中等 |
| 帧率计算 | 简单 | 需考虑 MUX 步数 | 小 |

### 13.2 串口输出格式（建议）

```
FRAME,<seq>,<timestamp_us>,<vref_mv>
R0,c0,c1,c2,...,c39
R1,c0,c1,c2,...,c39
...
R39,c0,c1,c2,...,c39
END
```

每帧数据量：40 行 × ~200 字符 ≈ 8KB。在 115200 baud 下约 700ms 传输。

**建议将波特率提升到 921600 或 2000000**，否则串口传输会成为帧率瓶颈。

### 13.3 扫描伪代码

```c
void scan_frame(void) {
    for (int row = 0; row < 40; row++) {
        // 1. 关闭所有 ROW MUX
        set_all_row_enable(HIGH);  // E=1 禁用

        // 2. 选择 ROW
        int mux_group = row / 16;  // 0, 1, 2
        int mux_ch = row % 16;     // 0~15
        set_row_s(mux_ch);         // S3/S2/S1/S0
        set_row_enable(mux_group, LOW);  // 使能对应 MUX

        // 3. 等待建立
        delay_us(T_SETTLE);

        // 4. 扫描 8 个 COL MUX 位置
        for (int mpos = 0; mpos < 8; mpos++) {
            set_col_mux_s(mpos);   // S2/S1/S0
            delay_us(T_MUX_SETTLE);

            // 5. 采集 5 路 ADC (N_AVG 次平均)
            uint32_t adc_sum[5] = {0};
            for (int avg = 0; avg < N_AVG; avg++) {
                start_adc3_5rank();
                wait_dma_complete();
                for (int ch = 0; ch < 5; ch++) {
                    adc_sum[ch] += dma_buffer[ch];
                }
            }

            // 6. 存储结果
            for (int ch = 0; ch < 5; ch++) {
                int col_idx = ch * 8 + mpos;
                frame_data[row][col_idx] = adc_sum[ch] / N_AVG;
            }
        }
    }
}
```

## 14. 风险评估与缓解

### 14.1 已识别风险

| 风险 | 等级 | 缓解措施 |
|---|---|---|
| Post-TIA MUX 引入噪声/偏移 | 中 | 4051 Ron ~80Ω 在 TIA 低阻输出下影响很小；可测量空载 MUX 一致性 |
| VREF 在 40 路分配后一致性不够 | 低 | 已增加缓冲运放；PCB 走线用宽线 |
| 串口带宽不够 | 高 | 必须提升波特率到 ≥921600 |
| PCB 走线串扰 | 中 | 使用地平面、保持模拟走线间距 ≥0.3mm |
| 74HC4067 漏电比 4051 大 | 低 | 同系列器件，规格相近；可在 PCB 上预留 4051 兼容方案 |
| 帧率不够 | 低 | 20Hz 对织物传感器足够；可优化 T_SETTLE 和 N_AVG |
| 40×40 传感器接线标定困难 | 中 | 预留测试点；固件支持单行/单列调试模式 |

### 14.2 降级方案

如果 40×40 一步到位有困难，可以先做一个 **16×16 中间版本**：
- ROW：1× 74HC4067（16 路）
- COL：4× MCP6004（16 路 TIA）+ 2× 74HC4051 post-TIA
- ADC：2 通道
- 同一块 PCB 可预留扩展到 40×40 的接口
