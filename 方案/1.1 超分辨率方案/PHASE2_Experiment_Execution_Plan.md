**版本**：v1.0
**配套文档**：`PHASE2_理论方案_感受野与超分辨可行性.md`
**执行者**：用户（硬件/夹具/操作）+ Codex（固件/采集/分析）
**预计实验室时间**：15–20 小时，建议分 5–8 次完成

# 0. 执行原则

沿用 1.0 阶段被证明有效的做法：

1. **一次只引入一个变量**
2. **每个 Gate 有明确 PASS/FAIL 判据，不通过不进下一步**
3. **原始数据不做任何滤波、不做 baseline 扣除后再存**（分析时再处理）
4. **所有条件切换后必须有独立的 OPEN/空载对照**
5. **发现异常先查接线和夹具，不要先怀疑物理**

新增一条 2.0 特有的：

6. **凡是涉及"力"的实验，力必须是已知的量，不能是"用手按"**。这是 2.0 与 1.0 最大的操作差别。

# E0 — 前置确认（约 1 小时）

## E0.1 几何参数测量

用游标卡尺测量并记录：

| 项目 | 方法 | 记录 |
|---|---|---|
| ROW 间距 `d_row` | 测第1根到第8根中心距，除以 7 | ___ mm |
| COL 间距 `d_col` | 同上 | ___ mm |
| 有效区尺寸 `L_row × L_col` | 首末导线中心距 | ___ × ___ mm |
| 导线宽度 `w` | 单根导电带宽度 | ___ mm |
| 织物厚度 `t` | 千分尺轻触，勿压实，测 5 处取均值 | ___ mm |

若 `d_row ≠ d_col`，后续全部分析必须分方向处理。

## E0.2 结构确认

目视 + 手机微距拍照记录：

- 织物类型：机织 / 针织 / 无纺 / 夹层结构？
- 压敏材料形态：连续涂层 / 仅交叉点涂覆 / 独立夹层膜？
- 是否已有覆盖层或保护层？
- 经纬方向标记（在织物边缘用记号笔标出经向，后续所有实验以此为角度基准）

这一步决定 §3.2 三条耦合通道中哪几条可能存在。

| U1 Pin6 | c1 | ___ | 10.15 kΩ | ☐ |
| U2 Pin2 | c2 | ___ | 10.09 kΩ | ☐ |
| U2 Pin6 | c3 | ___ | 9.71 kΩ | ☐ |
| U3 Pin2 | c4 | ___ | 10.00 kΩ | ☐ |
| U3 Pin6 | c5 | ___ | 10.02 kΩ | ☐ |
| U4 Pin2 | c6 | ___ | 9.97 kΩ | ☐ |

## E0.4 ROW 映射确认

启用 4051，依次选通 ROW0–ROW7，在每个 ROW 节点用万用表确认只有被选中的一路被拉到 ≈0 V。同时记录该 ROW 对应传感器上的第几根实体导线（从做了标记的那一边数起）。

记录表：

```

...
```

# 1. 测试夹具

**这是 2.0 阶段的最大工程量，也是所有定量实验的前提。** 没有它，后面 E1–E6 全部做不了。

## 1.1 需求指标

| 指标 | 要求 | 理由 |
|---|---|---|
| XY 定位步进 | ≤ `d/8` | 感受野形状需要足够采样点 |
| XY 重复定位精度 | ≤ `d/20` | 重复性实验的前提 |
| XY 行程 | ≥ `4d`（各方向 ±2d） | 覆盖感受野全部尾部 |
| 压头直径 | ≤ `d/4` | 近似点接触，见 §1.3 |
| 力已知精度 | ≤ ±5% | 标定曲线的精度上限 |
| 力可重复性 | ≤ ±2% | 比绝对精度更重要 |
| Z 向可控性 | 能稳定保持载荷 ≥ 60 s | 蠕变测量需要 |

## 1.2 三种实现方案

### 方案 A：3D 打印机改造 + 死重加载 ★ 推荐

**原理**：把打印头换成一个竖直滑动的加载杆，杆上挂已知质量的砝码。打印机 Z 轴下降到杆的限位环脱离托座时，砝码全部重量作用在传感器上，**继续下降不会改变力的大小**。

```
        打印机 Z 轴
             │
        ┌────┴────┐
        │  托座   │  ← 随 Z 轴移动
        └──┬───┬──┘
           │   │
        ┌──┴───┴──┐
        │ 限位环  │  ← Z 下降到一定深度后脱离托座
        └────┬────┘
             │
        ┌────┴────┐
        │  砝码   │  ← 已知质量 m，力 F = mg
        └────┬────┘
             │
        ┌────┴────┐
        │ 直线导轨 │  ← 保证只能竖直移动，无侧向力
        └────┬────┘
             │
             ▼ 压头（可更换）
      ═══════════════  传感器
```

**优点**
- 力的精度就是砝码的精度（电子秤可标到 0.1 g）
- 力与 Z 位置无关，不需要力传感器，不需要闭环
- XY 精度 0.1 mm 以下，远超需求
- 可编程，能自动跑数百个位置
- 成本极低（若已有 3D 打印机）

**注意事项**
- 直线导轨必须低摩擦，否则实际力小于砝码重量。装配后用电子秤反测校验：把整个夹具压在秤上，读数应等于砝码质量 ±2%
- 加载杆需要足够长的自由行程（≥ 5 mm），保证 Z 定位误差不影响力
- 需要在 G-code 中加入停留指令实现保持时间

**砝码组**：建议 10 g / 20 g / 50 g / 100 g / 200 g / 500 g / 1 kg，可组合出 10 g–1.88 kg
对应力：0.098 N – 18.4 N

### 方案 B：手动 XY 位移台 + 数显推拉力计

**优点**：直接读力，灵活
**缺点**：慢（每点 30 s+）、力靠手动保持不稳定、蠕变测量困难
**适用**：只做少量关键点验证，或作为方案 A 的力值交叉校验手段

### 方案 C：手动 XY 位移台 + 死重

**优点**：力精确、便宜
**缺点**：每换一个位置要手动摇，几百个点不现实
**适用**：E1（单点标定，位置不变只换力）非常合适

**建议组合**：E1 用方案 C，E2–E6 用方案 A。

## 1.3 压头设计

**压头直径必须远小于 `d`**，否则测到的是"接触面积 + 感受野"的卷积，无法分离。

| 用途 | 形状 | 直径 | 材料 |
|---|---|---|---|
| 感受野测量（E2/E3/E6） | 半球头 | ≤ `d/4` | 硬质（钢珠 / 树脂打印后打磨） |
| 压力标定（E1） | 平头圆柱 | ≈ `0.8d` | 硬质，端面平整 |
| 多点实验（E4） | 双半球头，固定间距 | ≤ `d/4` | 每个间距做一支 |

半球头用钢珠最理想（滚珠轴承钢珠，规格齐全且便宜，直径 1/1.5/2/3 mm 都有）。可用环氧粘在加载杆末端。

平头压头用于 E1 是因为标定需要**已知的接触面积**才能把力换算成压强：`P = F / A`。半球头的接触面积随力变化（赫兹接触），不适合做压强标定。

> **E1 用平头、E2 用球头，这两者不能互换。** 混用会导致标定曲线和感受野结果都不可信。

## 1.4 装夹与预张力

织物的预张力直接影响力学扩散（理论方案 §3.2 通道 A），必须固定且可复现。

**要求**：

1. 设计一个固定的装夹框（可 3D 打印），四边夹持，中间露出全部有效区
2. 装夹后织物应平整无褶皱，但**不施加明显张力**（"自然平摊"状态）
3. 在框上做标记，保证每次装夹位置一致
4. 装夹后不再移动，直到 E1–E6 全部完成
5. 若中途必须重新装夹，必须重跑一次 E5 的重复性检查作为对照

**记录**：装夹方式、夹持力（如用螺丝，记录扭矩或圈数）、装夹日期。

## 1.5 夹具验收

夹具搭好后，做以下检验才能开始正式实验：

| 检验项 | 方法 | 判据 |
|---|---|---|
| 力的准确性 | 整套夹具压在电子秤上 | 读数 = 砝码质量 ±2% |
| 力的重复性 | 同一位置加载 10 次 | 秤读数 std ≤ 1% |
| XY 重复定位 | 回到同一位置 10 次，测同一 taxel 响应 | ΔV std ≤ 2% |
| 压头垂直度 | 目视 + 压印检查 | 压痕圆形，无偏斜 |
| 无侧向力 | 加载时观察织物是否被拖动 | 无可见位移 |

# E1 — 压强标定与动态范围核对

**目的**：建立 `G = f(P)`，确定 `P_sat`，核对 Rf 是否需要更改
**夹具**：平头压头（直径 ≈ 0.8d），死重加载
**预计时间**：2 小时

## E1.1 协议

**位置**：选择阵列中心区域的一个 taxel（避开边缘），例如 (3,3) 或 (4,4)。记录选定坐标。

**压头**：平头圆柱，直径 `D_flat` = ___ mm，接触面积 `A = πD²/4` = ___ mm²

**加载序列**（每级保持并记录）：

```
空载基线 (30 s)
→ 10 g → 20 g → 50 g → 100 g → 200 g → 500 g → 1 kg → 1.5 kg → 2 kg
→ 卸载：2 kg → 1.5 kg → 1 kg → 500 g → 200 g → 100 g → 50 g → 20 g → 10 g
→ 空载恢复 (60 s)
```

**每级流程**：
1. 施加载荷
2. **连续采集 30 s**（不是采一个瞬时值——蠕变会让读数持续变化，需要完整曲线）
3. 切换到下一级

**重复**：整个加卸载循环重复 3 次，中间空载恢复 5 分钟。

**同时记录全部 8×8**，虽然只有目标点有响应，其余 63 点作为对照。

## E1.2 分析

对每级载荷：

```
F = m × 9.8 [N]
P = F / A  [Pa]，注意 A 用压头面积
ΔV = V_target − V_baseline
G = ΔV / (V_ref × Rf_target)   ← 用该通道实测 Rf
```

取每级 30 s 中**第 5–10 s 的均值**作为该级代表值（避开初始瞬态，也避开长期蠕变）。这个时间窗要在 E5 之后回过头来复核是否合理。

**拟合候选模型**（全部拟合，比较残差）：

| 模型 | 形式 |
|---|---|
| M1 单段幂律 | `G = a·P^β` |
| M2 线性 | `G = a·P + G₀` |
| M3 双段幂律 | `P < P_c` 用 `a₁P^β₁`，`P ≥ P_c` 用 `a₂P^β₂` |
| M4 饱和型 | `G = G_max·P/(P + P_half)` |

**输出**：
- 最优模型及参数
- `β` 值（决定线性近似是否可用，见理论方案 §4.2）
- `P_min`（3σ 可检测下限）
- `P_sat`（G 增长率降至低压区 20% 的压强）
- 迟滞环面积（加载/卸载曲线的差异，作为 E5 的预览）

## E1.3 动态范围核对（关键）

从数据中读出最大载荷（2 kg）下的 ΔV：

| 观察 | 判定 | 动作 |
|---|---|---|
| ΔV < 1.8 V 且曲线仍在上升 | 材料未饱和，电路未饱和 | Rf 可保持，甚至可增大提升低压灵敏度 |
| ΔV 接近 2.2 V 并平顶 | **电路饱和** | 必须降低 Rf（建议 4.7 kΩ），然后重跑 H1 验证 + 重跑 E1 |
| ΔV < 1.8 V 但曲线已平 | 材料饱和 | Rf 无需改，记录 `P_sat` 作为器件规格 |

**这两种饱和必须区分清楚**——一个是电路问题（可修），一个是材料特性（不可修，只能作为规格报告）。判别方法：临时把 Rf 换成一半（约 5 kΩ），若饱和点对应的压强不变则是材料饱和，若饱和消失则是电路饱和。

## E1 PASS 判据

- 标定曲线 R² ≥ 0.98
- 三次循环的一致性：同一载荷下 G 的相对偏差 ≤ 10%
- `P_min`、`P_sat`、`β` 全部确定
- 动态范围核对完成，Rf 决策做出
- 非目标 63 个通道无异常联动（变化 < 峰值的 5%）

# E2 — 单点感受野表征

**目的**：测定 `r`、判断各向异性、检验平移不变性 → 计算 `η`
**夹具**：半球压头（直径 ≤ d/4），XY 自动扫描
**预计时间**：4–6 小时（分两个子实验）

## E2.1 一维线扫描（先做，快速给出关键答案）

**位置基准**：选阵列中心的一个 taxel 作为原点，记为 T₀。

**三条扫描线**，全部通过 T₀ 中心：

```
线 1：沿经向（0°）      范围 −2d 到 +2d
线 2：沿纬向（90°）     范围 −2d 到 +2d
线 3：沿 45°            范围 −2d 到 +2d
```

**步进**：`d/8`（若 d = 10 mm 则 1.25 mm，取整用 1 mm）
**每条线点数**：约 33 点
**力值**：4 级 — 建议 0.5 N / 1 N / 2 N / 5 N（用砝码 50 g / 100 g / 200 g / 500 g）

**每点流程**：
1. XY 移动到位
2. Z 下降加载
3. **连续采集 8 s**（含加载瞬态）
4. Z 抬起
5. 等待 3 s（让织物回弹）

**总点数**：3 线 × 33 点 × 4 力 = 396 次加载，约 2–2.5 小时（自动运行）

## E2.2 二维面扫描（确认用，可只做 1 个力值）

**范围**：以 T₀ 为中心，`±1.5d × ±1.5d`
**步进**：`d/8`
**点数**：25 × 25 = 625 点
**力值**：取 E2.1 中信噪比最好的那一级，单一力值即可

约 2.5 小时自动运行。

## E2.3 平移不变性检查

在 **另外 2 个位置** 重复 E2.1 的线扫描（仅经向一条线，单一力值）：

- T₁：中心区另一个 taxel（检验中心区一致性）
- T₂：靠近边缘但非最外圈的 taxel（为 E6 做预备）

约 30 分钟。

## E2.4 分析

**对每个 taxel i，构建感受野函数**：

```
g_i(x, y) = G_i(刺激在 (x,y) 时) − G_i(空载)
```

**提取指标**：

| 指标 | 定义 | 用途 |
|---|---|---|
| `r₁₀(θ)` | 沿方向 θ，响应降至峰值 10% 的距离 | 主要半径定义 |
| `r_3σ(θ)` | 响应降至 3σ 噪声的距离 | 保守半径定义 |
| `r_FWHM(θ)` | 半高全宽的一半 | 便于与文献对比 |
| 各向异性比 | `r_max / r_min` | > 1.3 判定为显著各向异性 |
| 形状 | 拟合高斯 / 指数 / 十字形 | 决定 3.0 的核函数形式 |
| 峰值位置偏移 | 响应峰是否恰在几何交叉点 | 检验坐标映射正确性 |

**取 `r = min_θ r₁₀(θ)`（保守），计算：**

```
η = 2r / d
```

**对照理论方案 §5.2 表格得出判定。**

**平移不变性**：比较 T₀/T₁/T₂ 的 `r` 和形状，相对差异 ≤ 15% 则可用统一核，否则 3.0 必须逐点标定。

## E2.5 必须生成的图

1. `E2_line_profiles.png` — 三方向线扫描曲线，四个力值叠加
2. `E2_rf_2d_map.png` — 二维感受野热图 + 等高线
3. `E2_rf_polar.png` — `r(θ)` 极坐标图，直观展示各向异性
4. `E2_neighbor_response.png` — 刺激在 T₀ 时，周围 8 个 taxel 的响应
5. `E2_overlap_diagram.png` — 按实测 `r` 画出感受野圆在格点上的覆盖情况，标出 η
6. `E2_shift_invariance.png` — T₀/T₁/T₂ 三处感受野对比

## E2 PASS 判据

- 三个方向的 `r` 均已测定，噪声不影响判读
- `η` 计算完成并给出明确判定
- 各向异性已量化
- 平移不变性已评估
- 峰值位置与几何映射一致（若不一致，先查 E0 映射表）

# E3 — 覆盖层必要性检验

**目的**：检验零假设"裸器件不需要覆盖层"
**前置**：E2 完成，已知裸器件 `η`
**预计时间**：0–3 小时（取决于 E2 结果）

## E3.0 分支决策

```
E2 结果 η ≥ 2  →  E3 跳过，直接记录"本结构无需覆盖层"，进入 E4
                   （这是一个正面结论，要在论文里明确写出来）

E2 结果 η < 2  →  执行 E3.1
```

## E3.1 覆盖层厚度扫描

**材料选择**：软质、低迟滞、厚度均匀。候选：

- 硅胶片（Ecoflex / Dragon Skin，邵氏 00-30 左右）
- EVA 泡棉
- TPU 薄膜

**厚度序列**：0（裸，已有 E2 数据）/ 0.5 mm / 1 mm / 2 mm / 3 mm

**每个厚度**：重复 E2.1 的经向 + 纬向线扫描（省略 45°），单一力值（取 E2 中最优那一级）

**注意**：覆盖层必须平整贴合，不能有气泡或褶皱。每次更换后重测空载基线。

## E3.2 分析与选择

对每个厚度计算：

| 指标 | 期望趋势 |
|---|---|
| `r` | 随厚度增大 |
| `η` | 随厚度增大 |
| 峰值响应 `G_peak` | 随厚度**减小**（力被摊开了） |
| 信噪比 `G_peak/σ` | 随厚度减小 |
| 各向异性比 | 随厚度**减小**（覆盖层会让感受野变圆） |

**选择准则**（按优先级）：

1. `η ≥ 2`（硬性）
2. 在满足 1 的前提下，取**最小厚度**
3. 检查该厚度下 SNR 仍 ≥ 100
4. 检查 `P_min` 未因灵敏度下降而超出应用需求

**若所有厚度都无法同时满足 1 和 3** → 说明器件结构本身需要改（导线间距过大 / 压敏层过薄），这是一个重要的负面结论，应记录并作为 4.0 的器件迭代输入。

## E3 输出

一张核心图：`E3_thickness_tradeoff.png` — 横轴厚度，双纵轴分别为 η 和 SNR，标出选定点。

这张图如果做出来，本身就是论文里很有说服力的一张设计图。

# E4 — 叠加性与两点分辨

**目的**：量化 `ε_sup`，决定 3.0 技术路线；测定原始两点分辨极限
**夹具**：双压头，多个固定间距
**预计时间**：2–3 小时

> **这是 2.0 阶段信息量最大的实验。** 它单独决定 3.0 是走经典反演还是深度学习。

## E4.1 双压头制作

3D 打印一组双头压具，每支两个半球头（直径 ≤ d/4），间距固定：

```
间距序列：0.5d / 0.75d / 1.0d / 1.5d / 2.0d / 3.0d
```

每支压具需保证两个头**等高**（高度差 ≤ 0.1 mm），否则力分配不均。装配后在平整硬面上压印检查两个压痕深浅一致。

## E4.2 协议

对每个间距 `Δ`，在**两个方向**（经向排列、纬向排列）执行：

```
条件 A：只压 A 点      （另一个头用垫片抬高使其不接触）
条件 B：只压 B 点
条件 AB：同时压 A 和 B  （力加倍，使每个点的力与单点时相同）
```

**力的处理**：单点时施加 `F`，双点时施加 `2F`，保证每个接触点的力都是 `F`。这一点非常重要，否则比较的不是叠加性而是力的差异。

**位置**：A 点固定在阵列中心区某 taxel 上，B 点按间距顺延。

**每个条件**：连续采集 8 s，重复 3 次。

**总测量数**：6 间距 × 2 方向 × 3 条件 × 3 重复 = 108 次

## E4.3 分析

**叠加性残差**：

```
ΔG_A  = G(条件A) − G(空载)      [8×8 向量]
ΔG_B  = G(条件B) − G(空载)
ΔG_AB = G(条件AB) − G(空载)

ε_sup(Δ) = ‖ΔG_AB − (ΔG_A + ΔG_B)‖₂ / ‖ΔG_A + ΔG_B‖₂
```

**输出 `ε_sup(Δ)` 曲线**，并按理论方案 §4.3 判定：

| ε_sup | 3.0 路线 |
|---|---|
| < 5% | 经典线性反演（Tikhonov / LASSO），无需深度学习 |
| 5–20% | 非线性正向模型 + 迭代反演，或轻量网络 |
| > 20% | 数据驱动为主，深度学习有实质价值 |

**两点分辨（原始数据层面）**：

对每个间距的条件 AB，检查 8×8 原始热图中是否出现两个可分辨的局部极大值：

```
判据：两峰之间的谷值 ≤ 较低峰值的 80%（Rayleigh 类判据）
```

记录能分辨的最小间距 `Δ_min_raw`。这是**未经任何算法处理的物理极限**，将来 3.0 的超分辨结果必须与这个数字对比才有意义。

## E4.4 必须生成的图

1. `E4_superposition_error.png` — `ε_sup` vs 间距，两个方向
2. `E4_heatmaps_by_spacing.png` — 各间距下条件 AB 的 8×8 热图阵列
3. `E4_profile_comparison.png` — 沿两点连线的剖面，叠加 A、B、A+B、AB 四条曲线
4. `E4_two_point_limit.png` — 标出 `Δ_min_raw`

## E4 PASS 判据

- `ε_sup(Δ)` 曲线完整，6 个间距均有数据
- 3.0 技术路线判定明确
- `Δ_min_raw` 测定
- 两个方向的结果均已记录（各向异性会体现在这里）

# E5 — 稳定性表征（决定超分辨上限）

**目的**：量化 `ε_eff`（迟滞 + 蠕变 + 重复性 + 均匀性）
**预计时间**：3–4 小时（含长时间等待）

> 理论方案 §6.4 已论证：两点分辨上限 `Δ_min ≈ s·√ε_eff`。**这个实验直接决定 3.0 能做到多好。**

## E5.1 迟滞

E1 已采集加卸载数据，此处补充更密的循环：

- 中心 taxel，10 级加载 → 10 级卸载，每级保持 20 s
- 重复 5 个循环
- 力范围覆盖 `P_min` 到 `0.8·P_sat`

**指标**：

```
迟滞率 = max|G_加载(P) − G_卸载(P)| / G_max × 100%
```

## E5.2 蠕变

- 施加阶跃载荷（3 个力值：低 / 中 / 高）
- **保持 300 s**，全程连续采集
- 卸载后继续采集 300 s 观察恢复

**指标**：

```
蠕变率 = [G(300s) − G(5s)] / G(5s) × 100%
恢复残差 = [G(卸载后300s) − G(初始基线)] / G_max × 100%
```

**产出**：确定 E1–E4 中"加载后等多久读数"的最佳时间窗。若蠕变在 5–10 s 内已趋稳，则现有协议合理；若仍在快速变化，需要修改所有实验的时间窗并考虑重测。

> 这是一个可能推翻前面实验的结果。**建议把 E5.2 提前到 E1 之后立刻做**，而不是留到最后。

## E5.3 短期重复性

- 同一位置、同一力值、连续 20 次加载卸载（间隔 10 s）
- 计算 20 次读数的 std / mean

## E5.4 长期重复性

- 同一条件，间隔 1 小时测一次，共 8 次（覆盖一个工作日）
- 观察是否有单调漂移

## E5.5 通道均匀性（逐点标定表）

**这是 3.0 必需的输入数据。**

- 用平头压头，在**全部 64 个交叉点**上施加相同的中等载荷
- 每点采集 8 s，重复 3 次
- 建立 8×8 的 `G_response` 矩阵

**指标**：

```
均匀性 = std(G_64) / mean(G_64) × 100%
```

同时记录空载时每点的 `G₀`（即 `R₀` 的倒数）作为基线矩阵。

**产出**：`calibration_matrix.json`，包含每个交叉点的 `G₀` 和灵敏度系数。3.0 的所有数据都要先过这张表做归一化。

## E5.6 装夹重复性

- 完整拆下织物再重新装夹，重复 5 次
- 每次装夹后测 E5.5 的一个子集（例如对角线 8 个点）

**指标**：不同装夹之间的响应差异。若 > 20%，说明装夹方式需要改进，且 3.0 训练的模型不能跨装夹使用。

## E5.7 综合 `ε_eff`

```
ε_eff ≈ √( ε_迟滞² + ε_蠕变² + ε_重复² + ε_均匀² )
```

代入理论方案 §6.4：

```
预测两点分辨极限 Δ_min ≈ s · √ε_eff
```

**将这个预测值与 E4 实测的 `Δ_min_raw` 对比。** 若两者量级一致，说明理论模型正确，3.0 的性能预期可信；若差异巨大，需要检查是哪一项被低估了。

## E5 PASS 判据

- 迟滞率、蠕变率、重复性、均匀性四项全部量化
- `ε_eff` 计算完成
- 最佳采样时间窗确定
- `calibration_matrix.json` 生成
- 理论预测与 E4 实测的一致性已检验

# E6 — 边缘效应量化

**目的**：确定有效工作区，量化边缘退化
**背景**：H4 已观察到最外圈响应偏弱
**预计时间**：1–1.5 小时

## E6.1 协议

**径向线扫描**：从阵列中心沿经向一直扫到边缘外 `1d`，步进 `d/4`，固定力值。

**四边 + 四角**：分别在四条边的中点、四个角上做 E2.1 简化版线扫描（仅垂直于边的方向）。

**全阵列对比**：用 E5.5 的 64 点数据，按到边缘的距离分组统计。

## E6.2 分析

| 指标 | 说明 |
|---|---|
| 灵敏度 vs 到边距离 | 分组统计 `G_response` |
| 感受野 `r` vs 到边距离 | 边缘的 `r` 通常变小（缺少一侧的力学耦合） |
| 边缘 `η` | 若边缘 `η < 2`，该区域不能做超分辨 |
| 有效区定义 | 灵敏度 ≥ 中心区 80% 的区域范围 |

## E6.3 输出

- `E6_edge_profile.png` — 灵敏度随到边距离的变化
- `E6_effective_area.png` — 8×8 上标出有效区 / 退化区 / 不可用区
- 明确结论：**有效区是 8×8 全部，还是内部 6×6？**

若结论是 6×6，则 3.0 的所有工作在 6×6 上进行，8×8 的外圈仅作为边界条件辅助。这不是失败，是正确的工程界定。
