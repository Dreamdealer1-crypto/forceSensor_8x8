# 0. 本阶段的定位

1.0 阶段回答的是"读出链是否可信"。答案是肯定的：TIA 传递函数线性、串扰 Kghost < 1%、8×8 基线均匀、真实传感器有响应且可恢复。

2.0 阶段回答的是**完全不同的问题**：

> 这个器件承载的空间信息量有多少？超过物理像素数的重建，在物理上是否成立？成立到什么程度？

这个问题必须在写任何算法之前回答。原因很直接：如果器件的感受野不重叠，那么无论用插值、高斯过程还是深度网络，都只是在做平滑显示，不可能产生真实的定位精度提升。反过来，如果感受野充分重叠，那么连经典反演都可能已经够用，未必需要深度学习。

**2.0 阶段的产出不是算法，是器件的信息学参数。**

# 2. 读出链的数学基础

## 2.1 电压 → 电导：精确关系

1.0 阶段已验证的 TIA 传递函数：

```
V_out = V_ref × (1 + R_f / R_sensor)
```

移项得到本阶段真正要用的形式：

```
ΔV ≡ V_out − V_ref = V_ref × R_f × G_sensor
```

其中 `G_sensor = 1/R_sensor` 是被测交叉点的电导。

**这是一个值得强调的架构优势。** 零电位 TIA 读出的物理量线性正比于电导，而不是电阻。分压式读出电路（文献中常见）的输出对电阻是非线性的，需要额外反解。本架构直接给出电导，而压阻材料的电导通常比电阻更接近线性于压力——因为电导正比于导电通路数量，而通路数量随接触面积增长。

后文所有分析一律在电导域进行：

```
G_i = ΔV_i / (V_ref × R_f) = ΔV_i / 10.27  [单位：µS，ΔV 单位 mV]
```

数值系数：`V_ref × R_f = 1.03 × 9970 = 10269 V·Ω`，故 `G[µS] = ΔV[mV] / 10.27`。

> **注**：该系数使用 U1A 的 Rf。四颗运放的 Rf 实测在 9.71–10.15 kΩ 之间（±2%），每个通道应使用各自的 Rf 值，不可统一用一个数。这是 2.0 阶段必须做的通道级修正。

## 2.2 电导 → 压力：待标定

这一段没有第一性原理可依，必须实验拟合。压阻织物的常见候选模型：

| 模型 | 形式 | 物理图像 |
|---|---|---|
| 幂律 | `G = a·P^β` | 接触点数随压力幂律增长，最常用 |
| 线性+截距 | `G = a·P + G₀` | 低压区近似 |
| 双段幂律 | 分段拟合，转折点 `P_c` | 低压区快速增长、高压区饱和（文献常见） |
| 对数 | `G = a·ln(1+P/P₀)` | 强饱和情形 |

**不预设模型**。E1 实验采完后，用同一批数据拟合全部候选，按残差和外推行为选择。典型情况是双段幂律，`β` 在低压区 0.5–1.5、高压区降至 0.2–0.5。

需要同时得到的还有：

- `P_min`：可检测的最小压力（由噪声决定，见 §2.3）
- `P_sat`：进入饱和的压力（G 增长率降到低压区的 20% 以下）
- `β(P)`：局部灵敏度指数，决定不同压力段的分辨能力

## 2.3 动态范围核算

这是一个**必须在 2.0 早期核对的工程约束**，因为它可能要求改 Rf。

**上限（大压力端 / 低阻端）**：

MCP6002 为轨到轨输出，3.3 V 供电下实际最大输出约 3.25 V（轻载）。

```
ΔV_max = 3.25 − 1.03 = 2.22 V
G_max = 2.22 / 10.269 = 216 µS
R_min = 4.6 kΩ
```

**下限（小压力端 / 高阻端）**：

取 3σ 作为可检测阈值，σ_V ≈ 2 mV（保守取 H2 观察到的最大帧间 SD）：

```
ΔV_min = 6 mV
G_min = 0.58 µS
R_max = 1.71 MΩ
```

**当前状态核对**：

H4 单点按压峰值 ΔV = 890 mV
→ `G = 86.7 µS`，`R = 11.5 kΩ`
→ 已用掉动态范围的 **40%**

**结论与风险**：

- 手指轻按已占 40% 量程，**用力按压很可能贴轨饱和**。E1 必须包含大力测试来确认 `P_sat` 是材料饱和还是电路饱和——这两者完全不同，绝不能混为一谈。
- 若确认是电路饱和，应降低 Rf（例如降到 4.7 kΩ），代价是低压端灵敏度下降一倍。
- 若材料在电路饱和前就饱和了，则 Rf 无需改动，反而可以适当增大以提升低压灵敏度。

电导域动态范围：`216 / 0.58 ≈ 370 : 1`（约 51 dB）。这个数字在 E1 之后要重新核算，因为届时噪声和饱和点都是实测值。

# 3. 感受野的物理来源

## 3.1 本器件与文献器件的结构差异

这是本阶段最需要独立思考的地方，也是不能照搬文献的核心理由。

Science Advances (Kong et al. 2025) 的器件是**离散 taxel**：23 个直径 10 mm 的 CNT/PDMS 海绵块，彼此在电学上和机械上都完全分离，靠上面盖的 5 mm Dragon Skin 弹性体把力横向传递到邻近单元。**没有覆盖层，它们的感受野就等于单元自身尺寸，超分辨完全不成立。** 所以那篇论文必须加覆盖层。

本器件是**连续织物矩阵**，结构完全不同：

- ROW 和 COL 是贯穿整片织物的连续导线
- 压敏材料（很可能）是连续的涂层或夹层，不是分立的块
- 交叉点不是一个物理器件，只是两根导线的空间交叠位置

这种结构**天然可能已经具有感受野**，机制有三条，且互相独立：

## 3.2 三条可能的耦合通道

### 通道 A：面内力学传递

织物是一张膜。点载荷会在膜内产生张力场，影响范围远大于接触面积。织物的面内刚度越高、预张力越大，扩散范围越大。

**特征**：与压头大小无关，与织物张紧程度强相关。

### 通道 B：沿纱线的定向传递

经纱和纬纱是连续的。压在某根纱线上，力会沿这根纱线传导到相邻交叉点，但**不会等效地传到垂直方向**。

**特征**：这会产生**十字形/星形的各向异性感受野**，而不是文献中的圆形。这是本器件可能有的、文献器件不可能有的现象。

### 通道 C：压敏层横向电导扩散

如果压敏材料是连续的，那么按压位置的电阻率变化会同时改变周围多个交叉点的等效电阻——这是纯电学的感受野，不涉及任何力的扩散。

**特征**：与压敏层的方块电阻和交叉点接触电阻之比有关。可通过"压在两个交叉点正中间，看两侧响应比例"来间接判断。

> **重要区分**：通道 C 产生的耦合与 1.0 阶段消除的矩阵串扰（ghosting）**不是一回事**。矩阵串扰是通过其他交叉点的并联通路造成的伪像，零电位架构已将其压到 1% 以下。通道 C 是压敏层内部的连续导电扩散，零电位架构对它无能为力，也不应该消除它——它恰恰是超分辨所需的真实物理信息。
>
> 这个区分必须在论文里讲清楚，否则审稿人会认为你们的 Kghost 结论和感受野结论自相矛盾。

## 3.3 各向异性：一个可能的原创点

如果通道 B 显著，感受野将呈十字形而非圆形。后果：

- 用单一半径 `r` 描述感受野是错误的，必须用方向相关的 `r(θ)`
- 超分辨性能在经向、纬向、45° 方向上会不同
- 重建算法的核函数必须是各向异性的

文献全部基于离散 taxel + 各向同性弹性体，**没有处理过这个问题**。如果本器件确实呈现各向异性感受野，这本身就是有发表价值的发现，而不是需要"修正"的缺陷。

E2 必须包含三个方向的扫描，理由就在这里。

## 3.4 覆盖层：待检验变量，不是默认设计

综上，本阶段对覆盖层的立场是：

> **零假设 H₀：裸器件的感受野重叠率已满足超分辨条件，不需要覆盖层。**

E3 的作用是检验这个零假设，而不是"按文献做法加覆盖层"。三种可能结果都有明确的后续动作：

| E2/E3 结果 | 判定 | 后续 |
|---|---|---|
| 裸器件 η ≥ 2 | H₀ 成立 | 不加覆盖层，直接进 3.0。省一层结构、保住灵敏度和响应速度 |
| 裸器件 1 ≤ η < 2 | 部分成立 | 尝试最薄覆盖层，取满足 η ≥ 2 的最小厚度 |
| 裸器件 η < 1 | H₀ 不成立 | 必须加覆盖层，并做厚度扫描 |

（η 的定义见 §5.1）

无论哪种结果都是有价值的结论。**"我们证明了本结构不需要文献所需的覆盖层"是一个比"我们照着文献加了覆盖层"强得多的论述。**

# 4. 正向模型

## 4.1 两阶段模型（物理上正确的形式）

从施加压力到读数，实际经历两个阶段：

**阶段 1 — 力学扩散**（线性，可叠加）

```
P_eff(x,y) = ∬ K_mech(x−x′, y−y′) · P_app(x′,y′) dx′dy′
```

`K_mech` 是力学扩散核，由织物刚度、预张力、覆盖层（若有）决定。在小变形范围内这一步是线性的。

**阶段 2 — 压阻转换 + 电学积分**（非线性）

```
G_i = ∬ w_i(x,y) · σ[P_eff(x,y)] dx dy
```

`w_i` 是第 i 个交叉点的电学权重函数（由通道 C 决定），`σ[·]` 是 §2.2 标定的非线性压阻响应。

合起来：

```
G_i = ∬ w_i(x,y) · σ[ (K_mech ∗ P_app)(x,y) ] dx dy
```

**关键：非线性夹在两个线性算子中间。** 这决定了整体不可叠加。

## 4.2 单阶段线性近似及其成立条件

实际做算法时，我们希望能用简化形式：

```
G_i ≈ ∬ K(x−x_i, y−y_i) · P_app(x,y) dx dy
```

即"感受野核 K 与施加压力的卷积在格点采样"。这个近似成立需要：

1. **σ 在工作压力区间内近似线性**，或
2. **接触区域足够小**，使得 σ 的非线性只影响幅度不影响形状

条件 1 可由 E1 的 β 值判断：`β ≈ 1` 则近似良好，`β` 远离 1 则不成立。

## 4.3 叠加性是一个可检验命题

上述讨论直接给出 E4 的设计逻辑。定义叠加性残差：

```
ε_sup = ‖ G(A+B) − [G(A) + G(B)] ‖ / ‖ G(A) + G(B) ‖
```

其中 G(A)、G(B) 是单独施加时的电导增量向量（已扣基线），G(A+B) 是同时施加时的。

- `ε_sup < 5%`：线性近似成立 → 3.0 可用经典线性反演（Tikhonov / 稀疏重建），**很可能不需要深度学习**
- `5% ≤ ε_sup < 20%`：弱非线性 → 需要非线性正向模型 + 迭代反演，或轻量网络
- `ε_sup ≥ 20%`：强耦合 → 必须数据驱动，深度学习有实质价值

**这一个实验决定了 3.0 阶段的技术路线。** 它的重要性高于感受野形状本身。

同时要测 `ε_sup` 随两点间距的变化——预期间距越小、耦合越强、`ε_sup` 越大。这条曲线的拐点就是"可独立处理"的最小间距。

# 5. 超分辨可行性判据

## 5.1 感受野重叠率

定义感受野半径 `r`：以单点力刺激，某 taxel 的响应衰减到峰值 10%（或降至 3σ 噪声，取较大者）时的距离。

定义**重叠率**：

```
η = 2r / d
```

物理含义：η 是一个刺激能同时激活的 taxel 的空间跨度与格点间距之比。

## 5.2 判据分级

在方形格点上，考察任意刺激位置能激活几个 taxel：

| 条件 | η | 几何后果 | 超分辨可行性 |
|---|---|---|---|
| `r < 0.5d` | η < 1 | 存在盲区，格点间的刺激无任何响应 | **不可行**。任何"超分辨"都是插值幻觉 |
| `0.5d ≤ r < 0.71d` | 1 ≤ η < 1.41 | 无盲区，但多数位置只激活 1–2 个 | 仅能沿连线做一维亚像素定位，二维不可 |
| `0.71d ≤ r < d` | 1.41 ≤ η < 2 | 格心可激活 4 个，格点上邻居响应微弱 | 部分可行，性能随位置强烈起伏 |
| `r ≥ d` | η ≥ 2 | 任意位置至少 3–4 个 taxel 有显著响应 | **可行**。二维亚像素定位有充分约束 |

理由：二维平面上确定一个点的位置至少需要 3 个非共线的已知参考点。取 `r ≥ d` 保证了任意刺激位置周围都有 ≥3 个 taxel 落在感受野内。格心到四角距离为 `d/√2 ≈ 0.707d`，格点到四邻距离为 `d`——后者是更严格的约束，故以 `r ≥ d` 为充分条件。

**若感受野各向异性**，需分别计算各方向的 `r(θ)`，并以最小方向的 `η_min` 作为保守判据。

## 5.3 这是 2.0 阶段的核心判据

E2 测出 `r`，配合已知的 `d`，直接给出 η，从而判定：

- **超分辨是否成立**（η ≥ 2？）
- **是否需要覆盖层**（裸器件 η 不够时才需要）
- **3.0 阶段的输出网格该多大**（见 §6）

# 6. 分辨率的根本上限

这一节是整份文档最重要的部分，也是最容易在论文中被审稿人攻击的地方。必须自己先想清楚。

## 6.1 自由度约束

**每帧只有 64 个独立测量值。**

这是一个不可绕过的信息论约束。无论用什么算法，输出中最多只能有 64 个独立参数。

因此：

> **8×8 → 32×32 输出的 1024 个数值中，至少 960 个不是独立信息，而是由模型先验（平滑性、稀疏性、训练数据分布）填充的。**

这不意味着 32×32 输出没有意义——它意味着**必须正确表述它的意义**。

## 6.2 稀疏场景 vs 稠密场景

上述约束在两种场景下后果完全不同：

**稀疏场景**（少数孤立接触点）

一个接触点由 3 个参数描述：`(x, y, F)`。
- 1 个接触点 → 3 参数，64 个测量值 → **严重超定，可以解得极精确**
- 3 个接触点 → 9 参数 → 仍然超定
- 直到约 20 个接触点才开始欠定

**这就是"触觉超敏锐度"（tactile hyperacuity）的数学本质**：不是提高了成像分辨率，而是用大量测量约束少量参数。人类指尖能分辨 0.3 mm 的位移，而机械感受器间距是毫米级，靠的正是这个机制。

**稠密场景**（连续压力分布，如整只手掌压上去）

需要恢复的是一个连续场，自由度远超 64。此时：
- 感受野本身是一个低通滤波器，截止空间频率约 `1/(2r)`
- 高于截止频率的信息在测量中已被衰减到噪声以下，**物理上不可恢复**
- 任何声称恢复了这部分信息的算法，输出的是训练集先验，不是测量结果

## 6.3 单点定位精度（可以很好）

用 Cramér-Rao 下界估计。设 taxel i 对位于 u 的点刺激的响应为 `g_i(u)`，噪声 std 为 `σ`：

```
Fisher 信息矩阵  J = (1/σ²) Σᵢ ∇gᵢ ∇gᵢᵀ
定位精度下界     σ_loc ≥ √(tr(J⁻¹))
```

对高斯型感受野 `g_i(u) = A·exp(−|u−xᵢ|²/2s²)`，梯度峰值 `|∇g|_max ≈ 0.61A/s`，若有 N 个 taxel 显著响应：

```
σ_loc ≳ σ·s / (0.61·A·√N)
```

**代入本器件当前数据**（A = 890 mV，σ = 2 mV，N = 4）：

```
σ_loc ≳ s / 545
```

即噪声限下，定位精度可达感受野尺度的千分之二——远远好于需要。

**结论：单点定位不受噪声限制，而受系统误差限制**（见 §7）。文献中 SciAdv 达到 0.73 mm 定位误差（间距约 13 mm，即 18× 提升），且论文明确说明该误差由 1 mm 的数据采集步长决定，而非噪声。这与本节推导一致。

因此：**单点定位的线性提升倍数 10–20× 是现实可达的目标。**

## 6.4 两点分辨（会差很多）

这是完全不同的指标，也是最容易被高估的。

两个相距 Δ 的点，其合成响应与单个等效点的差异，在小 Δ 时正比于 `(Δ/s)²`（一阶项抵消，二阶项才携带"是两个点"的信息）。设系统相对幅度误差为 `ε_eff`，可分辨条件：

```
(Δ/s)² ≳ ε_eff   ⟹   Δ_min ≈ s·√ε_eff
```

代入不同误差水平：

| ε_eff | Δ_min |
|---|---|
| 1% | 0.10·s |
| 5% | 0.22·s |
| 20% | 0.45·s |
| 50% | 0.71·s |

**文献参照**：SciAdv 报告两点分辨 8 mm，其感受野 s ≈ 10.5 mm，即 `Δ_min ≈ 0.76s`，反推 `ε_eff ≈ 58%`。

也就是说，那篇 Science Advances 论文宣称 117× 的"超分辨倍率"，但**两点分辨只比原始间距（约 13 mm）改善到 8 mm，仅 1.6 倍**。

> **这是必须警惕的一点。文献中的"SR scale factor"是虚拟像素计数比（2700/23），不是分辨能力提升倍数。这两个数字相差近两个数量级。**
>
> 论文里如果用前者宣传、被审稿人用后者质疑，是很难辩护的。建议本项目从一开始就同时报告两个指标，并明确区分。

**由此得到一个重要推论**：两点分辨性能由 `ε_eff` 决定，而 `ε_eff` 主要来自材料的迟滞、蠕变、通道不均匀性——**不是来自电路噪声**。所以 E5（稳定性表征）不是可选的补充实验，而是直接决定超分辨上限的一级实验。

## 6.5 结论：应当报告哪些指标

基于以上分析，2.0 及后续阶段应报告：

| 指标 | 定义 | 预期量级 | 是否可宣传 |
|---|---|---|---|
| **单点定位 RMSE** | 已知位置点压，重建峰值位置的误差 | 可达 `d/10 – d/20` | ✅ 核心指标 |
| **两点分辨距离** | 能稳定分辨为两个峰的最小间距 | 约 `0.2d – 0.8d` | ✅ 诚实指标 |
| **有效空间带宽** | 感受野的 −3dB 截止空间频率 | `≈ 1/(2r)` | ✅ 物理上限 |
| 虚拟像素数 | 输出网格点数 | 任意 | ⚠️ 仅作显示说明，不作性能声称 |
| "SR 倍率" | 输出点数 / 物理点数 | 任意 | ❌ 不建议单独使用 |

# 7. 系统误差是主导项

§6.3 表明噪声不是瓶颈，§6.4 表明 `ε_eff` 才是。`ε_eff` 的来源，按预期影响从大到小：

| 误差源 | 机制 | 表征实验 | 缓解手段 |
|---|---|---|---|
| **迟滞** | 加载/卸载路径不同 | E5 加卸载环 | 建模（如 LSTM）或只用单向加载 |
| **蠕变** | 恒定载荷下电阻持续漂移 | E5 阶跃保持 | 固定采样延时；或建模补偿 |
| **通道不均匀** | 各交叉点 R₀ 和灵敏度不同 | E5 逐点标定 | 逐通道标定表（必做） |
| **Rf 差异** | 四颗运放 Rf 实测差 ±2% | 已测 | 逐通道使用实测 Rf（必做，成本为零） |
| **边缘效应** | 边缘交叉点力学边界条件不同 | E6 | 边缘单独标定，或裁剪有效区 |
| **装夹变化** | 预张力改变 → 整体灵敏度漂移 | E5 重复装夹 | 固定夹具，记录装夹状态 |
| 电路噪声 | ADC + 运放 | 已测 σ ≈ 0.6–2.5 mV | 已足够好，无需处理 |

**注意最后一行**：电路噪声已经不是限制因素。2.0 阶段不应该再花时间优化电路，应该全部投入到材料和力学表征上。这是 1.0 阶段扎实工作换来的红利。

# 9. 2.0 阶段通过判据

**PASS（可进入 3.0）需同时满足：**

1. `d` 已测定，感受野半径 `r` 在至少 3 个方向上已测定
2. 电导-压力标定曲线已建立，R² ≥ 0.98，且 `P_sat` 明确
3. 动态范围核对完成，若需改 Rf 已完成并重新验证 H1
4. `η` 已计算，且得到明确判定（可行 / 需覆盖层 / 不可行）
5. `ε_sup` 已量化，3.0 技术路线已确定
6. `ε_eff` 已量化（迟滞 + 蠕变 + 重复性）
7. 逐通道标定表已建立（R₀ 和灵敏度的 8×8 矩阵）
8. 全部原始数据可复现，采集条件完整记录

**CONDITIONAL（可进入 3.0 但需限定范围）：**

- η 在 1.41–2 之间：可做超分辨，但必须报告位置相关的性能起伏
- ε_sup > 20%：必须走数据驱动路线，且需要显著更多训练数据

**FAIL（不可进入 3.0）：**

- η < 1：**必须先改器件结构或加覆盖层**，否则超分辨在物理上不成立
- 电路在正常按压下饱和且未修正
- 重复性差到无法建立可信标定（例如同条件重复测量偏差 > 30%）

# 10. 与 3.0 的衔接

2.0 的产出直接决定 3.0 的形态：

```
E1 标定曲线      → 3.0 正向模型的 σ[P] 函数
E2 感受野核      → 3.0 正向模型的 K(x,y)，以及输出网格尺寸的选择依据
E3 覆盖层结论    → 器件最终形态冻结
E4 叠加性        → 3.0 算法路线选择（线性反演 vs 非线性 vs 深度学习）
E5 稳定性        → 3.0 性能上限的预测值，以及是否需要迟滞建模
E6 边缘          → 3.0 的有效区域定义和边界处理
```

**3.0 阶段的建议形态**（在 2.0 结论出来前不冻结）：

1. 用 E1+E2 结果构建正向模型
2. 用正向模型生成合成数据（避免海量实测）
3. 先做经典正则化反演作为 baseline
4. 用 E4 的实测多点数据验证 baseline
5. **只有当 baseline 明显不足时**，才引入深度学习

这个顺序保证了：无论深度学习效果如何，都有一个物理上可解释的 baseline 可以对照。这在论文里比"我们训了个网络，效果很好"强得多。
