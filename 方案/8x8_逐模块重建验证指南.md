# 8×8 压力矩阵 — 从零逐模块重建与验证指南

> **核心原则：每接一个模块，验证一个模块，确认PASS后才接下一个。**
> 
> 全程只需要：万用表 + STM32 Nucleo板 + 已有固件
>
> 预计总耗时：2~3小时（不赶时间，每步做扎实）

---

## STEP 0：完全拆除 + 整理元件

### 操作
1. STM32断电，拔掉USB
2. 把面包板上**所有线和元件全部拆掉**
3. 分类放好：
   - 4颗 MCP6002（标记U1/U2/U3/U4，或者后面重新分配也行）
   - 1颗 74HC4051
   - 8颗 10kΩ（反馈电阻 Rf）
   - 8颗 100pF（反馈电容 Cf）
   - 8颗 100kΩ（ROW上拉电阻）
   - 1颗 2.2kΩ（VREF分压）
   - 1颗 1kΩ（VREF分压）
   - 1颗 10µF（VREF滤波）
   - 5颗 100nF（1颗VREF + 4颗MCP6002去耦）
   - 杜邦线/跳线若干
4. 面包板擦干净，确认没有残留的短线头卡在孔里
5. 规划面包板布局——建议把4颗MCP6002排成一排，VREF电路靠近它们，4051放旁边

### 验证
- 目视确认面包板完全空
- 所有元件分类可辨认

### ✅ STEP 0 PASS条件
面包板干净，元件齐全，可以开始。

---

## STEP 1：电源总线

### 操作
1. STM32 Nucleo板通过USB上电
2. 从Nucleo引出两根线到面包板：
   - **3V3** → 面包板电源总线（红色标记）
   - **GND** → 面包板地线总线（蓝色/黑色标记）
3. 如果面包板有两侧电源轨，用跳线把两侧的3V3和GND分别桥接

### 万用表验证
| 测量点 | 预期 |
|---|---|
| 面包板3V3轨 对 GND轨 | 3.28~3.32V |
| 面包板3V3轨两侧桥接后电压差 | <10mV |

### ✅ STEP 1 PASS条件
- 3V3稳定在3.3V附近
- GND连通
- 无短路（若3V3明显偏低或Nucleo电源灯异常，检查短路）

---

## STEP 2：VREF分压电路

### 操作
在面包板上搭建VREF：

```
3V3 ──── 2.2kΩ ──── VREF节点 ──── 1kΩ ──── GND
                         │
                         ├── 10µF ── GND
                         │
                         └── 100nF ── GND
```

接线细节：
1. 3V3轨 → 2.2kΩ 一端
2. 2.2kΩ 另一端 → VREF节点（面包板上选一个明确的列作为VREF总线）
3. VREF节点 → 1kΩ → GND轨
4. VREF节点 → 10µF（注意电解电容极性，正极接VREF）→ GND轨
5. VREF节点 → 100nF → GND轨

**建议：VREF总线预留足够多的孔位，后面要从这里引8+2根线到MCP6002。**

### 万用表验证
| 测量点 | 预期 |
|---|---|
| VREF 对 GND | 1.02~1.04V |
| 触摸2.2k电阻 | 不发热 |
| 等待30秒再测VREF | 与首次测量差<5mV |

### ✅ STEP 2 PASS条件
- VREF ≈ 1.03V
- 稳定，不漂移
- 无异常发热
- 记录实测值：`VREF_measured = ____V`

---

## STEP 3：第一颗MCP6002（U1）—— 仅供电

### MCP6002 DIP-8 引脚图（从上方看，缺口朝左）
```
        ┌──U──┐
 Pin1  ─┤1   8├─ Pin8
 Pin2  ─┤2   7├─ Pin7
 Pin3  ─┤3   6├─ Pin6
 Pin4  ─┤4   5├─ Pin5
        └─────┘

Pin1 = VOUTA（A路输出）
Pin2 = VINA-（A路反相输入）
Pin3 = VINA+（A路同相输入）
Pin4 = VSS（地）
Pin5 = VINB+（B路同相输入）
Pin6 = VINB-（B路反相输入）
Pin7 = VOUTB（B路输出）
Pin8 = VDD（电源）
```

### 操作
1. 将U1插入面包板，跨中间沟槽
2. Pin8(VDD) → 3V3轨
3. Pin4(VSS) → GND轨
4. **100nF去耦电容**：尽量靠近U1，跨接Pin8所在列和Pin4所在列（即3V3和GND之间）
5. Pin3(VINA+) → VREF总线
6. Pin5(VINB+) → VREF总线
7. **此时不接反馈电阻/电容，不接输出线，Pin1/Pin2/Pin6/Pin7全部悬空**

### 万用表验证
| 测量点 | 预期 |
|---|---|
| U1 Pin8 对 GND | ≈ 3.3V |
| U1 Pin4 对 GND | 0V |
| U1 Pin3 对 GND | ≈ 1.03V（VREF） |
| U1 Pin5 对 GND | ≈ 1.03V（VREF） |
| 触摸芯片 | 不发热 |

### ✅ STEP 3 PASS条件
- 供电正确，同相输入正确
- 芯片不热
- VREF没有因为接入MCP6002而明显变化（回测VREF节点，应仍≈1.03V）

---

## STEP 4：U1 反馈网络 + 验证静态输出

### 操作
1. U1 A路反馈：Pin1 和 Pin2 之间并联接入 **10kΩ** 和 **100pF**
   - 10kΩ：Pin1列 → Pin2列
   - 100pF：Pin1列 → Pin2列（与10kΩ并联）
2. U1 B路反馈：Pin7 和 Pin6 之间并联接入 **10kΩ** 和 **100pF**
   - 同上方法
3. **Pin2和Pin6仍然不接任何外部信号（不接传感器、不接测试电阻）**

### 万用表验证
| 测量点 | 预期 | 说明 |
|---|---|---|
| U1 Pin1 对 GND | ≈ 1.03V（VREF） | 无输入电流时，输出=VREF |
| U1 Pin2 对 GND | ≈ 1.03V（VREF） | 虚短，跟随Pin3 |
| U1 Pin7 对 GND | ≈ 1.03V（VREF） | 同上 |
| U1 Pin6 对 GND | ≈ 1.03V（VREF） | 虚短，跟随Pin5 |

**关键判断：4个点都应该非常接近VREF。如果Pin1或Pin7贴近0V或3.3V，说明反馈接反了或短路了，立即检查。**

### ✅ STEP 4 PASS条件
- Pin1 ≈ VREF ± 20mV
- Pin7 ≈ VREF ± 20mV
- Pin2 ≈ VREF
- Pin6 ≈ VREF
- 记录：`U1_Pin1 = ____V, U1_Pin7 = ____V`

---

## STEP 5：U1 功能快测 —— 100kΩ接地测试

### 操作
1. 拿一颗 **100kΩ电阻**（不是反馈用的10kΩ！）
2. 一端接 **U1 Pin2**，另一端接 **GND**
3. 保持其他所有接线不变

### 理论预期
```
Vout = VREF × (1 + Rf/Rtest) = 1.03 × (1 + 10k/100k) = 1.03 × 1.1 ≈ 1.133V
```

### 万用表验证
| 测量点 | 预期 |
|---|---|
| U1 Pin1 | ≈ 1.13V（比VREF高约100mV） |
| U1 Pin2 | ≈ 1.03V（虚短仍保持） |
| U1 Pin7 | ≈ 1.03V（B路没接东西，不应变化） |

### 操作（测完后）
4. **拔掉这颗100kΩ测试电阻**
5. 重新测Pin1，确认回到≈1.03V

### ✅ STEP 5 PASS条件
- 接100kΩ时 Pin1 ≈ 1.13V（±30mV合理）
- 拔掉后 Pin1 恢复到 ≈ VREF
- Pin7 全程不变
- **U1A TIA功能确认正常**
- 记录：`U1_100k_test = ____V`

## STEP 6：U1 输出接入 STM32 ADC

### 操作
1. U1 Pin1 → **PF4**（Nucleo板上找到PF4引脚）→ 这是 COL0 / ADC3_INP9
2. U1 Pin7 → **PF5**（Nucleo板上找到PF5引脚）→ 这是 COL1 / ADC3_INP4

### Nucleo-H743ZI2 引脚位置提示
- PF4, PF5, PF6, PF7 通常在 CN12 Zio 连接器上
- PF10 在 CN12 上
- PC0, PC1, PC2 在 CN11 或 CN12 上
- 查你的Nucleo板丝印或数据手册确认

### 万用表验证
| 测量点 | 预期 |
|---|---|
| PF4引脚 对 GND | ≈ 1.03V（等于U1 Pin1） |
| PF5引脚 对 GND | ≈ 1.03V（等于U1 Pin7） |

### 软件验证（可选，建议做）
烧录已有固件，用8通道ADC模式（或ADC-02 polling模式），看串口输出：
- COL0 / r1 应该 ≈ 1.03V
- COL1 / r2 应该 ≈ 1.03V
- 其他6路因为还没接，可能是随机值或接近0V，这是正常的

如果COL0和COL1读数正确，说明 **MCP6002 → 跳线 → STM32引脚** 这条物理路径是通的。

### ✅ STEP 6 PASS条件
- 万用表确认PF4/PF5电压等于U1输出
- （可选）ADC读数与万用表一致

## STEP 13：全8路ADC基线验证

### 前提
此时面包板上应该有：
- VREF电路
- 4颗MCP6002，全部供电、反馈、同相输入到VREF、输出接到STM32
- 没有传感器、没有测试电阻、没有4051

### 操作
1. 烧录固件（8通道ADC模式）
2. 查看串口，确认8路全部读数

### 预期
全部8路 ≈ 1.03V（VREF），允许±20mV差异

### 万用表交叉验证
随机挑2~3路，用万用表直接测MCP6002输出引脚，与ADC读数对比，差异应<10mV。

### ✅ STEP 13 PASS条件
- 8路ADC全部在1.01~1.05V范围
- 无任何一路贴0V或3.3V
- ADC读数与万用表一致
- 记录所有8路基线值

### ⚠️ 如果某一路异常
- 先用万用表测对应MCP6002输出引脚
  - 如果MCP6002输出正常但ADC读错 → 检查跳线/STM32引脚
  - 如果MCP6002输出就不对 → 检查那颗芯片的供电/反馈/VREF连接

## STEP 14：4051 模块

### 操作
1. 74HC4051 插入面包板
2. 接线：

| 4051引脚 | 接到 |
|---|---|
| VCC | 3V3 |
| GND | GND |
| VEE | GND |
| Z / COM | GND |
| S0 | STM32 **PE14** |
| S1 | STM32 **PE11** |
| S2 | STM32 **PE9** |
| E / INH | STM32 **PG5** |
| Y0 | ROW0 节点（面包板上的一个列） |
| Y1 | ROW1 节点 |
| ... | ... |
| Y7 | ROW7 节点 |

3. 每个ROW节点同时接一颗 **100kΩ → VREF**：

```
Y0 ──┬── ROW0节点 ── 100kΩ ── VREF
     │
Y1 ──┬── ROW1节点 ── 100kΩ ── VREF
     │
 ... (共8路)
     │
Y7 ──┬── ROW7节点 ── 100kΩ ── VREF
```

**注意：此时ROW节点不接传感器，每个ROW只有两个东西连着：4051的Yn + 100kΩ到VREF。**

### 万用表验证（STM32上电但固件中E=1，4051禁用）

| 测量点 | 预期 | 说明 |
|---|---|---|
| 4051 VCC对GND | 3.3V | 供电正确 |
| 任意ROW节点对GND | ≈ 1.03V | 被100kΩ拉到VREF |
| 检查所有8个ROW | 全部≈1.03V | 确认8颗100kΩ都接对了 |

### 软件验证（可选但建议）
用固件把E=0，S2S1S0=000，选中ROW0：
- ROW0应该被拉到≈0V（通过4051接到GND）
- ROW1~ROW7仍然≈1.03V

手动切换到S2S1S0=001、010...111，每次确认只有被选中的ROW被拉低。

### ✅ STEP 14 PASS条件
- 4051禁用时：8个ROW全部≈VREF
- 4051启用后：被选中的ROW≈0V，其余≈VREF
- 8路100kΩ上拉全部工作正常
- 8路TIA输出（ADC读数）不应受4051操作影响（因为没接传感器）

## STEP 16：建立稳定测试夹具，准备H1传递函数

### 吸取上次教训
上次H1失败的根因是**测试电阻的接入和拔出导致面包板接触不稳定**。

### 建议做法
1. 从 **U1 Pin2** 的电气节点引出一根 **专用测试线TEST_A**，固定不动
2. 从 **GND** 引出一根 **专用测试线TEST_B**，固定不动
3. TEST_A 和 TEST_B 的末端用 **鳄鱼夹** 或 **面包板上两个相邻但独立的孔位**
4. 换电阻时只在TEST_A和TEST_B之间插拔，**绝不碰面包板上的其他线**
5. 每换一颗电阻之后：
   - 先用万用表测 TEST_A 和 TEST_B 之间的电阻值，确认电阻确实在路
   - 然后测 U1 Pin1 电压，确认TIA有响应
   - 最后才用ADC采集

### 另一个选择（更稳）
如果有一小块洞洞板或者第二块面包板，把测试电阻的切换放在那上面，用两根线接过来。这样主面包板完全不动。

## 如果某一步FAIL了怎么办

**不要跳过，不要继续往下接。**

1. 确认万用表表笔接对了、没有测错引脚
2. 检查最近一步接的线：是否插错孔、是否接触不良、是否元件方向反了
3. 如果是MCP6002输出异常（贴0V/3.3V）：
   - 检查反馈电阻是否真的在Pin1↔Pin2之间（不是Pin1到别的地方）
   - 检查Pin3是否真的接到了VREF
   - 拔出MCP6002重新插，确认没跨错沟槽
4. 如果排查不出来，**拍照当前状态发给我**，我帮你看
